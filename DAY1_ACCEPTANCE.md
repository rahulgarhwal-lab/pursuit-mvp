# Pursuit Day-1 Acceptance Gate

A story is not accepted because a button exists. The build passes only when the candidate can complete the real workflow.

## Required end-to-end behavior

- Master resume paste/upload (PDF, DOCX, TXT) produces a structured, reviewable Master Profile.
- Original source text remains immutable; structured corrections create profile versions.
- Both career-page URL and manual JD paste are first-class intake options.
- Imported/pasted JD is reviewed and confirmed before analysis.
- Analysis returns exactly five distinct hiring drivers rather than repeated JD prose.
- Mandatory/preferred/contextual language and knockout/logistics conditions are separated.
- Each criterion shows best verified evidence, fit status, gap type and explanation.
- ATS Readiness includes a visible component breakdown.
- Recruiter and hiring-manager outputs are ranges labeled as uncalibrated alignment estimates.
- Apply / Strong Adjacent / Stretch / Pass is driven by evidence and mandatory gaps.
- Gap validation asks only when a meaningful criterion is unresolved.
- Approved evidence can be saved to the Evidence Bank or promoted to the Master Profile.
- Saved evidence is reused on reanalysis and future JDs.
- Scope guardrails block direct-report, budget, enterprise, domain, production and metric inflation.
- Generated resume keeps evidence under the correct employer and role.
- Every included bullet has evidence provenance.
- Manual bullet edits must pass the truth guardrail before saving.
- Submission status shows Review Required vs Submission Ready.
- Word and PDF export work from the same approved draft.
- Evidence/profile/application state can be backed up and restored.
- Local data can be reset by the user.
- Quality Lab truth tests and the ndd-style regression test can be run without publishing private JDs.

## Post-launch, intentionally not required for this build

- Application lifecycle tracking.
- Company profile and interview-prep workspace.
- Post-interview question/feedback memory.
- Outcome-calibrated recruiter/hiring-manager probabilities.
- Payments, accounts, cloud sync and multi-user infrastructure.
